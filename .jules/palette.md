## 2025-05-15 - Global Shortcut Discoverability
**Learning:** Complex 3D simulations benefit greatly from global keyboard shortcuts, but they are often "hidden" from the user. Using hover-revealed hints (the `group-hover` pattern) provides a clean UI that stays out of the way for power users while offering immediate guidance to new users.
**Action:** Implement a consistent pattern for shortcut hints: absolutely positioned, small text, using a distinct color (like `#C084FC`), and revealed only on hover of the associated control.
