# Stellar Physics Skill & Reference

## Core Equations
1. **Mass-Luminosity Scaling**:
   $$L = M^{3.5 \text{ to } 4.0}$$
2. **Main Sequence Lifetime**:
   $$\tau = 10^{10} \times \left(\frac{M}{M_\odot}\right)^{-2.5} \text{ years}$$
3. **Effective Surface Temperature (Kelvin)**:
   $$T = 5778 \times \left(\frac{L}{R^2}\right)^{0.25}$$

## Spectral Classes & Planckian Locus Colors
- **O-Class**: $T > 30,000\text{ K}$ (Deep Electric Blue, `#7095ff`)
- **B-Class**: $10,000\text{ K} - 30,000\text{ K}$ (Blue-White, `#a6c4ff`)
- **A-Class**: $7,500\text{ K} - 10,000\text{ K}$ (Pure White, `#cadcff`)
- **F-Class**: $6,000\text{ K} - 7,500\text{ K}$ (Yellow-White, `#f8f7ff`)
- **G-Class**: $5,200\text{ K} - 6,000\text{ K}$ (Solar Yellow, `#fff4ea`)
- **K-Class**: $3,700\text{ K} - 5,200\text{ K}$ (Orange, `#ffd2a1`)
- **M-Class**: $2,400\text{ K} - 3,700\text{ K}$ (Red Dwarf, `#ffad63`)

## Phase Boundaries
- Protostar: $0 \le t < 0.05\tau$
- Main Sequence: $0.05\tau \le t < \tau$
- Red Giant: $\tau \le t < 1.2\tau$
- Supernova Flash: $1.2\tau \le t < 1.5\tau$ (Mass $\ge 8 M_\odot$)
- Remnant Phase (Neutron Star / Black Hole): $t \ge 1.5\tau$
